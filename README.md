# Piezas Accord

App de inventario y ventas del despiece de Honda Accord 2018–2020 Sport 1.5T.

- Funciona sin señal (guarda fotos, diagramas y datos en el teléfono).
- Datos y usuarios en Firebase (proyecto `piezas-accord`).
- La página se publica con GitHub Pages desde esta carpeta.

Carpeta `fuente/`: archivos originales para hacer cambios (`build.py` arma la página).
Reglas de seguridad de Firebase: `fuente/firestore.rules`.
